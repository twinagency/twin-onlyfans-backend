# Accounts (decided 2026-11-10)

Session limits are gone, so spreading one effort across 3 accounts is redundant. Use **one** account for everything (Opus high default). If it hits a hard limit, switch the whole session to the next account; never run the same effort from two accounts at once (two writers on one tree). The 3 accounts exist in T3 as `claudeAgent`, `claudeAgent_claude2`, `claudeAgent_claude3`; `delegate_task` uses whichever is current.
