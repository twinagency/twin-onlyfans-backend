"""Telegram event v1 / delivery-action v1 contract for the Fastt worker.

P1 deliverable. Offline, stdlib-only, import-safe: importing this package starts
nothing and touches no network, no database and no model. It mirrors the Node
validator in bot/src/engines/fastt-contract.ts so a Fastt-built event or action
is byte-compatible with what the Node gateway accepts.

The OnlyFans bridge (service/twin_bridge) already established the validation
lessons this reuses: string ids, UTF-16 length semantics, unpaired-surrogate
rejection, timezone-qualified timestamps normalised to canonical UTC, and
length-prefixed tuple hashing for identity keys. The OnlyFans wire contract
itself is NOT copied - the Telegram shapes differ.
"""
