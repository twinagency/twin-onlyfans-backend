## Disagreements with the kit (agent vs kit; owner decides)
1. **Pattern denies as the prod guard** — literal-text matching, bypassable. Kit answer: shipped `guard-main-push.sh` hook (branch-aware) + section 10 rulesets. Still not a security boundary: rulesets are.
2. **Blanket "never prod" vs sweeps that read prod** — pick: RO monitor identity + staging, or drop those signals. Kit answer: RO identity as written exception (section 03).
3. **Cron math/placement** — moot: sweeps run on T3 locally. Dead-man rule added.
4. **Homegrown RUM** (`perf_samples`, p95 > 20 %) is noisy at this traffic; baseline was gitignored. Kit answer: keep `useReportWebVitals`, add Lighthouse CI gate, move baseline to tracked `slop/baselines/`.
5. **DeepSeek as a lens** on adult-platform data — code-only + scrub, else drop. Kit answer: scrub gate (section 11), owner confirms.
6. **"No telemetry" for tokens** — OTel/ccusage is 3 env vars. Kit answer: section 06 cost ledger.
7. **Opus high/xhigh everywhere** — perceived speedup unreliable; measure first; Sonnet for mechanical fixes. Open.
8. **Inbox screenshots as proof** — only from seeded synthetic data. Adopted.
9. **`AskUserQuestion` denied + never stall** — pair with feature-list artifact + test-weakening guard + agent policy. Adopted (10).
10. **3-account spread** (`accounts.md`) — verify against Anthropic usage policy before relying on it. **guess** — owner checks.
11. **Secrets rule without a tool** — gitleaks is the enforcement. Adopted (10).
